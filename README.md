### Landing Page de Tienda de Cupcakes 🧁🍰
Este repositorio contiene el código de una landing page para una tienda de cupcakes, diseñada para destacar sus productos y servicios de manera visualmente atractiva. La página fue desarrollada usando HTML, CSS y JavaScript para un sitio web informativo y con interactividad básica.
